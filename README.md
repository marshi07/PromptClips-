# PromptClip - Full AI Web Tool

## Setup Instructions

1. Add the following to your .env.local:

HUGGINGFACE_API_KEY=your_huggingface_api_key
CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
CLERK_SECRET_KEY=your_clerk_secret_key
NEXT_PUBLIC_APP_URL=https://your-vercel-deployment-url

2. Push this project to GitHub.
3. Deploy via Vercel (connect your GitHub repo).
4. Add the same environment variables in Vercel settings.
5. Enjoy using PromptClip!

Includes:
- Hugging Face AI tool endpoints
- Clerk email/password login
- Dark/light theme
- Mobile + desktop responsive
- Promo video support on landing
